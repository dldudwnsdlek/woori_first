## 1. 도입 — WON 첫집 메이트 (0:20)

| 항목 | 내용 |
|---|---|
| 핵심 메시지 | 한마디면, 첫 집의 모든 순서를 AI가 챙긴다 |
| 화면 배치 의도 | 좌측에 서비스명과 한 줄 콘셉트, 우측 연한 블루 패널에 스마트폰 목업. 기능 나열 없이 ‘대화 한 번’만 보여 준다. |
| 사용한 시각 자료 | 우리WON뱅킹 로고(원본 비율), 첫 대화 화면(도형 기반 목업) |
| 애니메이션 구성 | 클릭 1 사용자 말풍선 → 클릭 2 AI 응답 카드 (아래에서 살짝 올라오며 페이드, 0.5초) |
| 강조할 문장 | ““저 12월 20일에 이사 가요.”” |

## 2. 문제 상황 — 첫 집의 복잡한 준비 (1:00)

| 항목 | 내용 |
|---|---|
| 핵심 메시지 | 확인할 것은 많고 순서는 복잡한데, 서류·일정·잔금이 따로 움직인다 |
| 화면 배치 의도 | 같은 크기의 카드 3장을 넓은 간격으로 떼어 놓고, 사이에 ‘끊어진 연결’ 표시. 하단에 통계 하나와 다음 장으로 넘기는 메시지 바. |
| 사용한 시각 자료 | 아이콘 카드 3장, 통계 1개(국토교통부 2024년도 주거실태조사: 임차 가구 평균 거주 3.6년) |
| 애니메이션 구성 | 클릭 1~3 카드 순차 등장 → 클릭 4 통계와 메시지 바 |
| 강조할 문장 | “문제는 정보를 찾는 것에서 끝나지 않습니다” |

## 3. 기획 배경 — 안내와 실행 사이의 공백 (0:50)

| 항목 | 내용 |
|---|---|
| 핵심 메시지 | 기존 서비스는 확인·안내까지, 첫집 메이트는 실행과 사후관리까지 |
| 화면 배치 의도 | 확인 → 계획 → 실행 → 사후관리 네 칸을 기준선으로, 위는 기존 서비스(두 칸 + 빈 점선), 아래는 제안(네 칸 모두 채움). 표가 아니라 ‘채워진 길이’로 차이를 보여 준다. |
| 사용한 시각 자료 | 4단계 트랙 다이어그램. 경쟁사 이름은 화면에 쓰지 않고 발표자 노트에만 근거를 둔다. |
| 애니메이션 구성 | 클릭 1 기존 행(+공백 강조) → 클릭 2 제안 행 → 클릭 3 결론 |
| 강조할 문장 | “차이는 ‘실행’입니다” |

## 4. 서비스 기획 — 네 단계 여정 (0:50)

| 항목 | 내용 |
|---|---|
| 핵심 메시지 | 한마디 입력 → 네 단계. 핵심은 3단계(잔금 설계·안전한 이체) |
| 화면 배치 의도 | 상단에 고객의 한마디, 아래에 가로 4단계 카드. 3단계만 블루 채움·큰 크기·‘핵심’ 표시로 구분. 폰 화면은 넣지 않는다(뒤에서 자세히). |
| 사용한 시각 자료 | 단계 카드 4장(아이콘 + 시점 + 한 줄 설명) |
| 애니메이션 구성 | 클릭 1 1·2단계 → 클릭 2 3단계 → 클릭 3 4단계 |
| 강조할 문장 | “은행이기 때문에 할 수 있는 단계입니다” |

## 5. 서비스 UI ① 계약 위험점검 (0:55)

| 항목 | 내용 |
|---|---|
| 핵심 메시지 | 계약서 사진 한 장 → 정보 추출 → 위험 신호 → 다음 단계에 반영 |
| 화면 배치 의도 | 우측 패널의 폰이 주인공. 좌측에는 번호 콜아웃 3개만 두고, 각 콜아웃이 폰 화면의 해당 영역과 같은 클릭에 나타난다. |
| 사용한 시각 자료 | 위험점검 화면(읽은 내용 카드, 신호등, 점검 5항목). 구축 제안임을 밝히는 각주. |
| 애니메이션 구성 | 클릭 1 추출 결과 → 클릭 2 신호등·목록 → 클릭 3 근저당 강조(주황 테두리) |
| 강조할 문장 | “경고에서 멈추지 않고, 잔금일 순서에 미리 넣어 둡니다” |

## 6. 서비스 UI ② 맞춤형 일정 관리 (0:45)

| 항목 | 내용 |
|---|---|
| 핵심 메시지 | 이사일만 알면 할 일을 역산한다 — 휴일이면 영업일로 먼저 조정 |
| 화면 배치 의도 | 좌측에 ‘12.20(일) → 12.18(금)’ 날짜 타일을 크게, 우측 폰에는 D-56 카드와 체크리스트. D-day 숫자와 체크만으로 이해되게 한다. |
| 사용한 시각 자료 | 일정표 화면(D-56, 11개 중 3개 완료, 다음 할 일 D-45). 예시 일정임을 밝히는 각주. |
| 애니메이션 구성 | 클릭 1 날짜 조정 → 클릭 2 체크리스트 → 클릭 3 다음 할 일 강조 |
| 강조할 문장 | “고객은 순서를 외우지 않아도 됩니다” |

## 7. 서비스 UI ③ 잔금 지도 (1:20)

| 항목 | 내용 |
|---|---|
| 핵심 메시지 | 돈이 어디서 와서 어디로 가는지 한눈에 — 그리고 빠뜨리기 쉬운 부대비용 620만 원 |
| 화면 배치 의도 | 좌측에 ‘출처 3개 → 잔금’ 흐름도, 그 아래 부족분을 주황 띠로 분리. 우측 폰은 같은 내용을 앱 화면으로. 금융상품 설명 대신 금액과 흐름만 남긴다. |
| 사용한 시각 자료 | 자금 흐름 다이어그램(2억 + 2억 4,000만 + 1,000만 = 4억 5,000만), 부대비용 내역(350만 + 200만 + 70만 = 620만), 잔금 지도 화면 |
| 애니메이션 구성 | 클릭 1 출처 → 클릭 2 합계 일치 → 클릭 3 부족분 → 클릭 4 해결 |
| 강조할 문장 | “잔금은 맞췄는데 당일에 돈이 모자라는 상황이, 바로 여기서 생깁니다” |

## 8. 서비스 UI ④ 잔금일 돈 길 내비게이션 (1:45)

| 항목 | 내용 |
|---|---|
| 핵심 메시지 | 조건이 확인돼야 이체가 열리고, 마지막 송금은 고객이 승인한다 |
| 화면 배치 의도 | 좌측에 잔금일 하루 타임라인(08:30 → 10:30), 우측 폰에 같은 진행 상황. 처음엔 모든 단계가 회색 ‘대기’, 발표자가 말하는 순서대로 하나씩 켜진다. 마지막 단계만 주황(고객 승인). |
| 사용한 시각 자료 | 4단계 타임라인, ‘잔금일 돈 길’ 화면(안심금고, 단계 체크, 잠긴 승인 카드 → 열린 승인 카드), 새 기능 3가지 칩 |
| 애니메이션 구성 | 클릭 1~3 단계 활성화(좌·우 동시) → 클릭 4 승인 화면 → 클릭 5 안전장치 → 클릭 6 새 기능 3가지 |
| 강조할 문장 | “이 송금은 자동으로 나가지 않습니다. 고객이 직접 승인해야 실행됩니다” |

## 9. 입주 후 경험과 기대효과 (1:05)

| 항목 | 내용 |
|---|---|
| 핵심 메시지 | 첫 집의 첫날이 우리은행과의 새로운 금융 관계가 된다 |
| 화면 배치 의도 | 우측 폰은 입주 다음 날의 우리WON뱅킹 홈(첫집 메이트 카드). 좌측은 고객·은행·사회 세 장의 카드. |
| 사용한 시각 자료 | 홈 화면(자동이체 3건 연결, 다음 할 일), 기대효과 카드 3장. 근거 없는 정량 수치는 넣지 않고 각주로 검증 필요성을 밝힌다. |
| 애니메이션 구성 | 클릭 1 고객 → 클릭 2 은행 → 클릭 3 사회 |
| 강조할 문장 | “은행에는 주거래 관계의 시작점이 됩니다” |

## 10. 실현 가능성 · 안전장치 · 마무리 (1:10)

| 항목 | 내용 |
|---|---|
| 핵심 메시지 | 전부 새로 만들지 않고, 기존 금융 기능을 안전하게 연결한다 |
| 화면 배치 의도 | 좌측에 단계별 ‘기존 기반 / 신규 개발·연계 검토’ 표와 안전장치 3가지, 우측은 블루 패널. 마지막 클릭에 패널 위로 마무리 문장만 크게 나타난다. |
| 사용한 시각 자료 | 4행 비교 표, 안전장치 칩 3개, 마무리 문장(46pt) |
| 애니메이션 구성 | 클릭 1 기존 기반 → 클릭 2 신규 → 클릭 3 안전장치 → 클릭 4 마무리 문장(페이드) |
| 강조할 문장 | “첫 집의 첫날부터, 우리은행이 끝까지 함께.” |
